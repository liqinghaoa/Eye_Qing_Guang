## 数据预处理版本

### PP-v1：基线预处理

1. 对原始眼底图执行 EXIF 方向纠正，并统一转换为 RGB。
2. 按原图长边等比缩放至 384 像素，使用双线性插值；短边用黑色画布居中补齐，得到 `3×384×384` 输入。
3. 仅训练集执行确定性随机增强：水平翻转概率 0.5、随机旋转 `[-10°, +10°]`、亮度系数 `[0.9, 1.1]`、对比度系数 `[0.9, 1.1]`。随机数由 `seed + epoch + sample_id` 决定，避免不同 rank/worker 调度改变增强结果。
4. 像素按 `x / 127.5 - 1.0` 转为 `[-1, 1]`；验证和推理不执行随机增强。

该版本用于三个从头训练的基线，目的是保持模型网络变化以外的输入尺寸、增强和训练流程一致。

### PP-v2：ImageNet 配方预处理

`PP-v2` 与 `PP-v1` 保持相同的 EXIF/RGB 处理、384 尺寸、黑边补齐和训练集增强；唯一的数据预处理变化是把归一化改为 ImageNet 推荐值：

```text
mean = [0.485, 0.456, 0.406]
std  = [0.229, 0.224, 0.225]
```

该版本与 ImageNet-1K 初始化的 EfficientNetV2-S 配套。它更符合该预训练权重的输入分布，但也意味着预训练实验相对 `PP-v1` 基线是“初始化 + 归一化配方”的组合对照，而不是纯粹的初始化消融。

### PP-v3：512 FOV缓存预处理

`PP-v3-A` 和 `PP-v3-B` 使用相同的512×512 FOV裁剪、等比缩放、黑色居中补齐、训练增强和离线缓存流程，区别在模型权重所需的输入归一化：

- `PP-v3-A`（timm EfficientNetV2-S）：mean/std 为 `[0.5,0.5,0.5]` / `[0.5,0.5,0.5]`，与 `tf_efficientnetv2_s.in21k_ft_in1k` 的 pretrained_cfg 一致。
- `PP-v3-B`（timm ConvNeXt-Tiny）：mean/std 为 `[0.485,0.456,0.406]` / `[0.229,0.224,0.225]`，同时适用于本项目的 `fb_in22k_ft_in1k` 和 `fb_in1k` 实验。

采用 `PP-v3` 的实验均使用 `fov_presized_letterbox_v2` 缓存版本，训练阶段保留水平翻转、旋转、亮度和对比度增强，独立验证与test关闭随机增强。该512缓存流程不是原始ImageNet的224/288中心裁剪评测流程，属于当前青光眼任务的统一输入协议。

### PP-v4：288 FOV缓存预处理

`PP-v4-A` 和 `PP-v4-B` 沿用 `PP-v3` 的RGB/FOV裁剪、等比缩放、黑色居中补齐、训练增强与 `fov_presized_letterbox_v2` 缓存协议，但输出尺寸固定为288×288，使用与512版分离的 `glaucoma_first_fov288_cache_v1`。FOV检测的预览尺寸仍为512；该值不是模型输入尺寸。

- `PP-v4-A`（timm EfficientNetV2-S）：mean/std 均为 `[0.5,0.5,0.5]`；当前只有配置，尚无本地训练结果。
- `PP-v4-B`（timm ConvNeXt-Tiny）：mean/std 为 `[0.485,0.456,0.406]` / `[0.229,0.224,0.225]`；已有288版 ImageNet-1K 实验结果。

同尺寸两种模型可复用图像缓存，但归一化在读取时分别执行。288与512实验的缓存目录互不混用。

## 损失函数版本

### Loss-v1：无权重二元交叉熵

三个从头训练基线与 `torchvision` EfficientNetV2-S 预训练实验均输出单个未激活 logit，并计算：

```text
BCEWithLogitsLoss(logit, label)
```

实现直接调用 `torch.nn.functional.binary_cross_entropy_with_logits`。该写法将 sigmoid 与二元交叉熵合并，数值上比先做 sigmoid 再算 BCE 更稳定。当前版本没有使用正类权重、Focal Loss、标签平滑或阈值参与训练；类别不平衡主要由标准二分类目标和验证指标共同监控。最终分类阈值不写入损失函数，特异度约束下的阈值仅在验证集上描述性计算。

### Loss-v2：正类加权二元交叉熵

timm 两阶段预训练实验，以及新增的 ConvNeXt ImageNet-1K 512/288和最终重训实验，使用：

```text
BCEWithLogitsLoss(logit, label, pos_weight=5.0)
```

其中 `pos_weight=5` 只将正类损失项放大5倍；不等于阳性比例，也不等于所有样本权重都乘5。上述 timm 实验均不使用自动类别比例重算、WeightedRandomSampler、Focal Loss或额外 class weight。保留独立valid的开发实验使用连续概率 AUROC 选优；train+valid最终重训固定7轮，不再执行验证集选优。提交标签按固定0.5阈值生成。

## 数据集使用思路

### 官方划分与训练/验证职责

- 使用项目清单中的官方 `train` 和 `valid`，没有从官方训练集中再次随机切分 train/val。
- 官方 `train` 用于梯度更新：51,396 张，其中阳性 1,657 张。
- 官方 `valid` 用于每轮验证、选择验证 AUROC 最好的 `best.pt`、报告 AUROC/AP/特异度约束下召回率：5,849 张，其中阳性 191 张。
- 三个基线及保留官方valid独立验证的预训练开发实验遵循上述口径，可以比较各自的valid结果。ConvNeXt ImageNet-1K 的train+valid最终重训是例外：官方valid合并进训练，只能使用此前开发实验固定的7轮方案，不能再报告独立valid指标。
